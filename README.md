# OriginalityChecker — Stage 1

This is the Stage 1 multi-page student workspace.

## Included
- Dashboard
- New Check
- My Documents
- Reports
- Citation Checker
- AI Analysis
- Settings
- Responsive mobile/desktop interface
- PDF/DOCX/TXT upload
- Existing Stage 1 analysis API
- Browser-local report history
- Render Docker deployment

## Deploy
Use the existing Render Web Service and deploy the latest GitHub commit. Docker is already configured.

## Important
The current similarity corpus is a demonstration corpus. It is NOT a complete internet/academic plagiarism index. AI-writing results are probabilistic indicators, not proof of authorship. The real retrieval engine and advanced analysis are planned for later stages.
